# Dependency matrix

Who owns what, which direction dependencies run, and which duplicated names are on
their way out. `tools/check_dependencies.py` enforces this file: it fails the build
if a deprecation is declared in code but absent here (or vice versa), if the
import graph has a cycle, if a dependency is unpinned, or if a model file has been
copied instead of imported.

## Direction of dependency

```
apgi-framework  ──►  apgi-implementation  ──►  apgi-system
(reference equations,   (computation engine,     (production scoring,
 fixtures, teaching      estimation, runtime)     consumes published
 package)                                         versions only)
```

* `apgi-framework` never depends on `apgi-system`.
* `apgi-implementation` (this repository) never imports `apgi_system`, and never
  vendors or copies `apgi-framework` model files; it consumes the framework through
  published versions or pinned commits.
* Cross-repository references are by version or commit recorded in the run manifest
  (`runtime/run_manifest.py`), not by file copy.

## Canonical owners

| Module group | Canonical owner | Notes |
| --- | --- | --- |
| Reference equations, fixtures | apgi-framework | `apgi-framework/src/apgi` is a fixture-conformant teaching package without numerical authority. |
| `models.reduced` (`apgi_reduced`) | apgi-implementation | The single qualified numerical reference (D14); see `qualification/`. |
| `estimation/` (PyMC model, recovery, identifiability) | apgi-implementation | Decision D2. Consumed by K7a/K7c and production scoring. |
| `adapters/`, `runtime/`, `model_registry/`, `engine/` | apgi-implementation | Computation engine. |
| `core/`, `pipeline.py`, `hierarchy/`, `oscillation/`, `reservoir/`, `stats/`, `energy/`, `active_inference/` | apgi-implementation | Pipeline-backed variants (no reference authority). |
| `gates/gate-table.yaml` | apgi-implementation | Generated by `tools/run_k7.py`; drives the battery allow-list. |

## Pinned third-party packages

Every runtime and optional dependency carries an upper bound or an exact pin in
`pyproject.toml` and `requirements.txt`. Bounds stop at the next major version (for example
`numpy>=1.24,<3.0`) so installation works on current Python releases without disturbing other
packages. PyMC is optional (`apgi[estimation]`); the numpy estimators in
`estimation/fitting.py` need nothing beyond `scipy`.

## Deprecations

Each legacy spelling is retired through `adapters.version_adapter`, which emits a
`DeprecationWarning` naming the canonical replacement and the removal release. A
duplicate without an entry here fails `tools/check_dependencies.py`.
